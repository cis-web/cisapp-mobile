کاتێک ڕێکخستنەکانت تەواو کرد، دەتوانیت بەردەوام بیت.

سامسۆنگ / گەلاکسی

١. چالاککردنی ئاگاداری
  • بڕۆ بۆ ڕێکخستنەکان (Settings) ← ئەپەکان (Apps).
  • لیستەکەدا ئەپی پەیمانگا (CIS) هەڵبژێرە.
  • کرتە لەسەر Notifications بکە و دڵنیابەرەوە کرداری سەرەکی و هەموو جۆرەکانی ئاگاداری کراونەتەوە.
٢. لابردنی سنووردارکردنی باتەری
  • لە هەمان لاپەڕەی ئەپەکە، کرتە لەسەر Battery بکە.
  • بژاردەی Unrestricted هەڵبژێرە — نەک Optimized یان Restricted.
  • بگەڕێوە بۆ ڕێکخستنەکان ← Battery and device care ← Background usage limits.
  • ئەگەر ئەپەکە لەناو لیستی Sleeping apps دایە، لایبدە؛ باشترە بیخەیتە ناو Never sleeping apps.
٣. قوفڵکردنی ئەپ لە لیستی ئەپە کراوەکان
  • دوگمەی Recent apps بگرە.
  • لەسەر وێنۆچکەی ئەپەکە کرتە بکە و دوگمەی قوفڵ (Lock) چالاک بکە.

شاومی / ڕێدمی (MIUI)

لەسەر مۆبایلی شاومی/ڕێدمی، هەنگاوی Autostart زۆر گرنگە — بەبێ ئەوە ئاگاداری ناگاتێ.
١. چالاککردنی ئاگاداری
  • ڕێکخستنەکان ← ئەپەکان (Apps) ← بەڕێوەبردنی ئەپەکان (Manage apps).
  • ئەپی پەیمانگا هەڵبژێرە ← Notifications ← چالاکی بکە.
٢. چالاککردنی Autostart
  • ڕێکخستنەکان ← ئەپەکان ← ڕێکخستنی زیاتر (Permissions) ← Autostart.
  • بگەڕێ بۆ ئەپی پەیمانگا و دوگمەکەی چالاک بکە.
٣. لابردنی سنووردارکردنی باتەری
  • ڕێکخستنەکان ← باتەری (Battery) ← App battery saver.
  • ئەپی پەیمانگا هەڵبژێرە و No restrictions هەڵبژێرە.
٤. قوفڵکردنی ئەپ
  • لە لیستی Recent apps، بۆ خوارەوە swipe بکە بۆ دەرکەوتنی دوگمەی قوفڵ و کرتەی لێ بکە.
دەتوانیت ڕاستەوخۆ لاپەڕەی ڕێکخستنی ئەپ بکەیتەوە

هواوی (EMUI)

١. چالاککردنی ئاگاداری
  • ڕێکخستنەکان ← ئەپەکان (Apps) ← ئەپی پەیمانگا ← Notifications ← چالاکی بکە.
٢. ڕێکخستنی دەستپێکردنی خۆکاری (App launch)
  • ڕێکخستنەکان ← باتەری (Battery) ← App launch.
  • بۆ ئەپی پەیمانگا، کرداری خۆکار (Manage automatically) لابدە.
  • هەر سێ بژاردەکە چالاک بکە: Auto-launch، Secondary launch، Run in background.
٣. قوفڵکردنی ئەپ
  • لە لیستی ئەپە کراوەکان، ئەپەکە قوفڵ بکە وەک لە سامسۆنگدا باسکرا.
دەتوانیت ڕاستەوخۆ لاپەڕەی ڕێکخستنی ئەپ بکەیتەوە

مۆبایلی تر

  • بڕۆ بۆ ڕێکخستنەکان ← ئەپەکان ← ئەپی پەیمانگا (CIS)، و دڵنیابەرەوە Notifications چالاکە.
  • لە بەشی باتەری، هەوڵبدە هەر جۆرە سنووردارکردنێکی باتەری بۆ ئەم ئەپە لابدەیت (Unrestricted / No optimization).
  • ئەگەر بژاردەی Autostart یان Background activity هەبوو، چالاکی بکە.
دەتوانیت ڕاستەوخۆ لاپەڕەی ڕێکخستنی ئەپ بکەیتەوە

تێبینی گشتی بۆ هەموو مۆبایلێک

  • پێویستە ئینتەرنێت (Wi-Fi یان داتا) هەمیشە چالاک بێت بۆ وەرگرتنی ئاگاداری.
  • پاش گۆڕینی هەر ڕێکخستنێک، باشترە مۆبایلەکە دووبارە دەستپێبکرێتەوە (Restart).
  • ئەگەر دیسان ئاگاداری نەگەیشت، ئەپەکە بسڕەوە و دووبارە دامەزرێنە، پاشان جارێکی تر بچۆرەژوورەوە.
  • زۆربەی ئەم کێشانە کێشەی مۆبایلەکەیە نەک ئەپەکە — بۆیە ڕێکخستنەکانی سەرەوە زۆر گرنگن.
